## 五、跨源偏差登记（本批新增/收口）

1. **PR-P04 引用偏差（本批新登记——§二 2.11）**：指标手册 v1.0/v1.2 与 Prism 细则双源一致定义 PR-P04 = Vulkan 1.3 计算着色器可用；M34-P4 起 power::display/kernel::fb/METRICS 三处引用「PR-P04 口径：电源策略与显示侧的协同语义面」为**编号误引**——电源协同语义面在手册无对应编号项。处置：三处引用注记随 M39-收尾批次勘误（实体面零改动——M34-P4 语义面/挂接结构面/t79 (g) 回环全部保留）；Vulkan 计算队列挂账随 GPU 域批次。
2. **介质失联挂账摘牌（ROADMAP §七 5）**：22 份原件复原 + 本表成像；「PDF 重取后补 Prism/Mirror 细则逐条对账」之原scope 由本表全 15 族对账超额收口。
3. **数值类指标环境 B 挂账口径复核**：108 项中 47 项挂账、42 项结构面——其中时限/吞吐/延迟类数值验收全部受「环境 B（真机窗口）」前置约束，与本表逐一标注一致；TCG 值只作回归基线（§五 工作流纪律 4）。
4. **pulse.txt 介质劣化**：逐字符空格化产物（非原件）——不作对账依据，Pulse 族以细则 PDF 为准（§二 2.12）。
