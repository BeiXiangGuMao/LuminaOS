1. 冷却基线 **75–120s**（RUNBOOK 口径 60–120s 内收紧——本轮 75s/80s/90s/
   120s 四档实证均脱窗；过短（0–60s）实证不足）。
2. 复跑前**零改码**（改码即污染族属定性——真缺陷域除外）。

   转揭雷流程）。
