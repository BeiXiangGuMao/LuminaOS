# ADR-0007：glyph 同源模型——细则原文为 24 源网格，ROADMAP 记载勘误

- 状态：已裁决（Accepted，含 ROADMAP 勘误）
- 日期：2026-10-22
- 关联：《美术设计指南》v1.2.0 §5.1（888 行）/ v1.0.0 §对应章（830 行）；ROADMAP §1.2 glyph 行；M30 里程碑

## 背景

ROADMAP §1.2 对 glyph 的评级记载为「**同源模型反向**（细则以 96 为母版）→ ADR-0007」，倾向方案为「按细则改（96 母版重绘 24/48）」。

本次裁决对照细则原文复核：

- **《美术设计指南》v1.2.0 §5.1（第 888 行）**：「图标以 **24 网格为源网格**，向 48 与 96 两档同源放大：三档共用同一几何描述，仅网格密度与笔画宽度不同——笔画分别为 2px、4px、8px」；
- **v1.0.0 对应章（第 830 行）**：同口径（「图标以 24 网格为源网格，向 48 与 96 两档同源放大」）——两个版本一致，非版本间漂移；
- 96/192/384 三档出现在指南**第 8 章插画**节（插画交付档位），与第 5 章图标体系分属两个资产类；
- 现 glyph 实现（`BASE_GRID = 24`，`SIZES = [24, 48, 96]`，`scale_factor` ×1/×2/×4，`HOVER_SCALE = 1.05` / `HOVER_DURATION_MS = 120`）与细则 §5.1 逐条吻合，含悬停参数（指南 5 章悬停 1.05×/120ms 走 Ripple 弹簧）。

即：**ROADMAP 的「96 母版」记载系研究员误读**——把第 8 章插画交付档位（96/192/384）误当作第 5 章图标母版口径。

## 决策

**现实现合规，无需改。** 三项随附动作：

1. **ROADMAP §1.2 glyph 行勘误**（本 ADR 落盘时同步修正）：评级结论改记「同源模型合规（24 源网格 ×1/×2/×4，细则 §5.1 对账一致）」，ADR 指针指向本文；
2. glyph/lib.rs 头注释补细则 §5.1 对账指针与「插画 96/192/384 为另一资产类」的辨析注释，防后续读者再犯同型误读；
3. M30（glyph 渲染库里程碑）的真实缺口维持 ROADMAP 原有其他维度结论：**渲染库本体为 0**（现仅网格换算纯函数，无几何描述/编译产物面），M30 按细则「源文件 + 编译产物 + 元数据」交付流程补齐——这与母版方向无关，不受本勘误影响。

## 理由

- ADR 裁决的第一纪律是**对照细则原文**，而非沿袭规划文档的中间结论（ROADMAP §一明确「冲突时以规范手册为准」）；本例是「验收锚 = 指标编号口径」纪律的一次实践；
- 若按误读执行「96 母版重绘」，将把合规实现改造成违规（与 §5.1 的 2px/4px/8px 笔画规则体系全部脱钩），并波及悬停参数与关键线体系；
- 勘误公开记录（而非静默修正）的价值：防止「ROADMAP 曾记载反向」的残影在未来评审中再次发酵，同时为「插画 ≠ 图标」的辨析留下可检索的裁决存档。

## 影响面与回滚

- **影响面**：ROADMAP 一行修正；glyph/lib.rs 注释数行；M30 任务书以本 ADR 为母版口径锚。无代码语义变更，无测试面影响。
- **回滚**：纯文档勘误，可静默回退但无回退理由（原文实证充分）。

## 替代方案

- **a) 按细则改（ROADMAP 原倾向：96 母版）**：否决——细则原文恰恰相反（v1.0/v1.2 双版本一致），该方案建立在误读之上；保留此替代方案记录以存证裁决过程。
- **b) 保留现模型且不做任何记录**：否决——ROADMAP 的误读记载会继续误导后续评审与 lint 组件矩阵对账，必须显式勘误闭环。
